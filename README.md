# Mario · Portfolio

Portfolio personal — desarrollador web y automatización de procesos. HTML, CSS y JavaScript sin frameworks ni dependencias de build.

Navegación tipo diapositivas (pantalla completa, una sección a la vez) con teclado, rueda del ratón y gestos táctiles. Por debajo de 820px de ancho cae a scroll normal.

## Estructura

```
index.html      contenido y estructura de cada sección
css/styles.css  tokens de diseño, componentes, animaciones
js/main.js      motor de diapositivas, datos de proyectos, carrusel
```

## Desarrollo local

Al ser HTML/CSS/JS estático, basta con abrir `index.html` en el navegador o servirlo con cualquier servidor estático (por ejemplo `npx serve`).
